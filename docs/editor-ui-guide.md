# ページ編集画面の使い方

## ページを開いて編集する

左の「ページ」から対象を選びます。キャンバスと「レイヤー」は同じ要素を選択します。キャンバスの文字はダブルクリックで直接編集でき、右のインスペクタでは選択した要素の内容と見た目を変更できます。素材や共通部品を使うときは左のパネルから選びます。

キャンバス下部で端末の幅を切り替え、各幅での見た目を確認します。「表示幅」でキャンバスの幅だけを変えられます。「編集モード」の幅の設定を変更する前に、その幅を使うページを確認してください。

「?」キーでショートカットの一覧を開けます。「⌘K」（Windows では Ctrl+K）を使うと、要素名やページ内の文章を検索し、編集操作を呼び出せます。

## 保存・公開・復元

「下書き保存」で作業内容を保存し、「プレビュー」でページを確認します。公開前の確認では、公開先と差分を確認してから公開します。競合した場合は、手元と最新版の差分を確認して次の操作を選びます。版履歴を利用できるサイトでは、以前の版を開いて比較し、必要に応じて復元できます。

接続された操作はサイトによって異なります。読み取り専用の文書では、画面に案内された編集元で修正します。

ローカルで試すにはリポジトリのルートで `npm ci` と `npm run demo` を実行してください。ホストとの接続は[ホスト契約](editor-contract.md)を参照してください。
