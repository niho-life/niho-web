# 共通エディターの利用案内

この文書は画面上で利用者が知るべき挙動に絞ります。adapter の型・認証・保存契約は[ホスト接続契約](editor-host-contract.md)、wire format は[Editing API 契約](editing-api-contract.md)を参照してください。実装の細部はコードとテストを正とします。

## React不要の文書編集操作

編集操作は React に依存しない `editor-model` にあります。公開 API と CLI も同じ操作を使います。詳細は[ホスト接続契約](editor-host-contract.md)を参照してください。

## ホストへの接続

画面はホストの `EditorAdapter` を通じて文書を読み書きします。認証・権限・保存先の責任は[ホスト接続契約](editor-host-contract.md)にあります。

## 要素の名前

要素名は文書本文の一部ではなく、ホストが管理する補助情報です。名前の表示や編集が使えないホストでは、通常の文書編集は続けられます。

## 操作単位の保存

操作のまとめ送り、競合からの復帰、undo/redo の詳細は[保存・履歴契約](save-history-contract.md)を正とします。

## キーボードショートカット

エディターで `?` を押すと、現在利用できるショートカットが表示されます。Mac の `⌘` は Windows では Ctrl に対応します。

## レイヤー

キャンバスとレイヤーパネルは同じ選択状態を示します。レイヤーから選択しても文書の内容は変わりません。

## ホストの表示部品を同じ iframe へ差し込む

サイト固有の表示部品が必要な場合はホストが明示的に供給します。副作用のない preview を使い、詳しい接続方法は[ビルダー接続ガイド](builder-integration-guide.md)を参照してください。

## 共通部品

共通部品の保存・展開・競合は[共通部品契約](component-contract.md)を正とします。

## 表示領域（slots）

表示領域の編集範囲と検証は[ブロック表示領域契約](block-slot-contract.md)を参照してください。

## サイトとページのスタイル所有権

画面では編集対象の範囲を選び、値の所有者を確認してから変更します。保存・公開・優先順位は[サイト共通スタイル契約](site-styles-contract.md)を参照してください。

## ブレークポイント構成の目安

Mobile・Tablet・PC の3段を出発点にし、実際に違うレイアウトが必要な場合だけ段を増やします。整理時は変更内容を確認し、幅別プレビューを見てから適用します。
